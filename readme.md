# 📊 CSV AI Analyst (GenAI Project)

An AI-powered data analysis chatbot that lets users upload a CSV file and interact with it using natural language.

---

## 🚀 What This App Does

This application allows you to:

- 📂 Upload any CSV file
- 💬 Ask questions in plain English
- ⚙️ Automatically generate Pandas queries
- 📊 Visualize data with charts
- 🧠 Use a local LLM (Llama3 via Ollama)

---

## 🧠 Example Queries

Try asking:

- "Show first 5 rows"
- "Count total records"
- "Average salary by department"
- "Plot sales by region"
- "Bar graph of age vs income"

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Matplotlib
- Ollama (Llama3)

---

## 📦 Requirements

Make sure you have:

- Python 3.9+
- Ollama installed
